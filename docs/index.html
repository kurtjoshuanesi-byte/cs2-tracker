CS2 Account Tracker

Track your CS2 G2G account bans and cooldowns. Stay on top of when accounts are ready to play.

Python · FastAPI · SQLite PyWebView · Tailwind CSS

Features

🔒

PIN Lock Security

4-digit PIN protects your data. API stays locked until correct PIN entered. 5 wrong attempts = 30-second lockout.

🔔

Smart Notifications

Get alerts 1 day, 2 hours, and 10 minutes before bans expire. Plus an alert exactly when ready. History saved so alerts don't repeat.

⏰

Quiet Hours (DND)

Set a time range to mute notifications. Perfect for sleeping or working without interruptions.

📜

Ban History

Old bans saved automatically when you set a new Ban Start. Open with History button. Entries can be removed.

🗑️

Bulk Select & Delete

Tick checkboxes to select accounts and delete multiple at once. Backup created before deleting.

⏳

Real-time Countdowns

Tracks exactly when a ban expires down to the second. Auto-sorts with closest to expiring at top.
