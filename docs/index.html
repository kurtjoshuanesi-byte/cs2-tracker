CS2 Tracker Showcase

Experience the full power of CS2 Tracker, a modern, secure, and feature-rich application for managing CS2 accounts and bans.

Key Features

  • Secure PIN authentication with PBKDF2 hashing
  • Real-time ban management (start, duration, history)
  • CSV import/export with flexible header mapping
  • Auto‑backup of account data every hour
  • Self‑updating desktop executable via GitHub Releases
  • Cross‑platform desktop UI with system tray integration
  • Responsive web UI on FastAPI backend

Live Demo

Run the application locally:

uvicorn main:app --reload

Then open http://127.0.0.1:8000 in your browser.
